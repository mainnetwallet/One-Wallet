# Security Policy

One Wallet handles private keys and signing. Please report vulnerabilities privately.

## Reporting

Use GitHub's **Report a vulnerability** (Security tab → Advisories) on this repository.
Do not open public issues for security problems and do not post keys, seed phrases or exploit details publicly.

Include: affected version, steps to reproduce, impact, and any suggested fix.

## Scope

Key handling, signing, lock/biometric, JS ↔ native bridges, RPC/bridge/swap transaction construction, and the in-app browser.

## Supported versions

Only the latest release is supported.
